操作你的電腦。

出門在外要取用檔案、開啟桌面程式或處理臨時工作，打開 Mizar 就能直接連回自己的電腦。

完整鍵鼠與傳輸

同步畫面、聲音、鍵盤滑鼠、剪貼簿與檔案，操作方式與本機一致。

完成裝置配對後，需要時打開即可直接建立連線。

無中轉，資料留本機

連線只在你的兩台裝置之間進行，金鑰與內容絕不經過第三方。

連線流程

配對一次，直接相連。

1

配對裝置

在被控裝置當面確認，或輸入一次性 10 位數配對碼。

2

交換位址

透過公共服務協助兩台裝置找到彼此，過程不經手任何畫面。

3

直接操控

兩台裝置建立加密直連，立即操作桌面或手機。

用 Google 帳號登入

選用功能 · 尚未推出

日後推出時，登入 Google 帳號可讓你的各台裝置自動互相發現，無需額外建立 Mizar 帳號。

Mizar 會向 Google 要求你的帳號身分、電子郵件地址，以及它在你 Google 雲端硬碟裡專用的隱藏資料夾；裡面只放一樣東西：加密過的裝置清單。

它看不到你的其他檔案，也不會把任何資料傳給我們或其他人。

Mizar 使用從 Google API 取得的資訊，以及將這些資訊傳輸給其他應用程式時，都會遵守Google API 服務使用者資料政策，包括其中的「有限使用」（Limited Use）規定。
