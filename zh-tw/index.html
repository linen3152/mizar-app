用 Google 帳號登入

選用的功能，尚未推出。登入之後，你的每一台裝置都看得到其他幾台。

Mizar 會向 Google 要求你的帳號身分、電子郵件地址，以及它在你 Google 雲端硬碟裡專用的隱藏資料夾；裡面只放一樣東西：加密過的裝置清單。

它看不到你的其他檔案，也不會把任何資料傳給我們或其他人。

Mizar 使用從 Google API 取得的資訊，以及將這些資訊傳輸給其他應用程式時，都會遵守 Google API 服務使用者資料政策，包括其中的「有限使用」（Limited Use）規定。
