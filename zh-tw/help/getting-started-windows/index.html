所有使用說明

在 Windows 上開始使用

安裝、允許、連線。

安裝

在每台電腦上執行安裝程式。它只會加入程式本身、「開始」功能表的捷徑，和「已安裝的應用程式」裡的一個項目。

讓電腦可以被遙控

  1. 在那台電腦上開啟 Mizar，進入這台電腦。
  2. 開啟允許遙控這台電腦。
  3. 需要的話，再允許登入畫面與系統管理員提示。這會安裝背景服務，Windows 會詢問一次。

連線

  1. 在你手上的裝置開啟裝置。同一個網路裡的電腦會自己出現。
  2. 選那台電腦，請電腦前的人按允許。
  3. 之後只要選它，就會直接連上。

不在同一個網路？請用一次性配對碼配對。

連線期間

快速選單裡有全螢幕、鎖定滑鼠（玩遊戲用）、Ctrl+Alt+Del、剪貼簿、檔案、螢幕與畫質。
