乾淨地解除安裝

移除 Mizar 和它安裝的所有東西。

Windows

  1. 開啟設定 > 應用程式 > 已安裝的應用程式，找到 Mizar，選解除安裝。
  2. 選擇保留我的資料或全部移除。
  3. 同意 Windows 的提示。

會移除什麼

項目是否移除
程式、捷徑，以及「已安裝的應用程式」裡的項目一律移除
背景服務、虛擬螢幕驅動程式、防火牆規則只要是 Mizar 裝的，一律移除
路由器上開的連接埠一律移除。連不到路由器時，它會在大約兩小時內自己關閉
配對紀錄、設定與紀錄檔選「全部移除」時

Mizar 只移除自己安裝的東西，其他一概不碰。同一台電腦上其他 Windows 帳號的 Mizar 資料會留著，由他們自己刪除。

只想移除其中一項（例如背景服務），請用 App 裡的已安裝的元件。

Android

照平常的方式解除安裝。你收到的檔案會留在 Download/Mizar。

之後
