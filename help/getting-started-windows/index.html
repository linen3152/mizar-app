Getting started on Windows

Install, allow, connect.

Install

Run the installer on each PC. It adds the program, a Start menu shortcut and an entry in Installed apps, and nothing else.

Let a PC be controlled

  1. On that PC, open Mizar and go to This PC.
  2. Turn on Allow control of this PC.
  3. Optional: also allow the sign-in screen and administrator prompts. This installs a background service; Windows asks for permission once.

Connect

  1. On the device you hold, open Devices. PCs on the same network appear by themselves.
  2. Choose the PC. Someone at the PC presses Allow.
  3. From then on, choosing the PC connects at once.

Not on the same network? Pair with a one-time code.

While connected

The quick menu holds full screen, mouse capture for games, Ctrl+Alt+Del, clipboard, files, display and quality.
