Pair with a one-time code

Add a device that is somewhere else, with ten digits.

On the PC

  1. Open This PC and choose Show code under Pair a device that is not on this network.
  2. If asked, agree to turn on remote access.
  3. The PC shows ten digits, like 482 913 5027, and a QR code. They last ten minutes and work once.

On the other device

  1. Open Devices and choose Add with a code.
  2. Type the digits, or scan the QR code, and press Pair.
  3. Check that it found your PC, then choose Add this PC.

Confirm

The PC asks whether to allow the device. Both screens show the same six digits; compare them if you like, then press Allow. Unanswered, the question closes itself after 30 seconds.

If it does not work

You seeDo this
The code has expiredShow a new code
Wrong code, or too many triesShow a new code and type it again
Cannot reach the other deviceCheck that both are online and that their clocks are set automatically
Paired, but cannot connectSee Reach a PC from anywhere

A code alone is never enough: nothing can control the PC until someone at the PC allows it.
